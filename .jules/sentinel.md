## 2024-05-24 - Use -LiteralPath for path-based cmdlets
**Vulnerability:** Wildcard injection in path-based cmdlets (like `Get-ChildItem`, `Test-Path`, `Move-Item`, `Get-FileHash`, `New-Item`) when using `-Path` (or relying on positional binding to `-Path`) with input that is meant to be a literal path but might contain wildcard characters like `[]` or `*`. This allows executing cmdlets against unintended files, potentially leading to information disclosure or data destruction (in the case of move or delete).
**Learning:** This codebase uses PowerShell scripts for file management, which involves passing file paths to various cmdlets. Using `-Path` for these operations makes them vulnerable to wildcard evaluation.
**Prevention:** Always use `-LiteralPath` instead of `-Path` (or implicit `-Path`) for path-based cmdlets when handling file paths (especially user input, file names, or folder paths that are not explicitly intended to contain wildcards) to prevent unexpected wildcard injection.
